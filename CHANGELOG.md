# Changelog - AuraCraft

### Initial Release
- Access all chests, barrels, and storage containers within a 20-block radius from your crafting table.
- Native Vanilla Recipe Book integration:
  - "Showing Craftable" filter accounts for nearby container resources.
  - Green outline highlights recipes that depend on linked containers.
- Zero-lag chunk-based scanning with 1-second debounce caching.
- Atomic Fabric Transfer API operations to prevent item duplication and voiding.
- Leftover crafting grid items automatically return to linked containers when closing or switching recipes.
- Multilingual support: English (`en_us`), French (`fr_fr`), and Spanish (`es_es`).
